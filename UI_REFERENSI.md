# Ringkasan Arahan UI/UX yang Dipakai

Desain tidak menyalin template komersial. Tampilan dibuat custom dengan inspirasi praktik umum dari dashboard modern, sidebar admin, card statistik, form ringkas, kontras yang jelas, dan micro-interaction.

Prinsip yang digunakan:

1. Sidebar sederhana dengan grouping menu.
2. Dashboard memakai card statistik, grafik ringkas, dan ranking item.
3. Form transaksi dibuat bertahap dan field terkait dikelompokkan.
4. Tombol aksi memakai warna konsisten.
5. Role membatasi menu serta aksi agar pengguna tidak bingung.
6. Desain responsif memakai CSS grid dan media query.
7. Aksesibilitas dasar: label input eksplisit, kontras status tidak hanya bergantung pada warna, ukuran target tombol cukup besar, dan layout mobile disederhanakan.

Referensi riset yang dipakai saat merancang:

- Bootstrap documentation untuk pola responsive grid dan komponen antarmuka.
- Material Design untuk prinsip navigasi, permukaan, dan hierarki visual.
- W3C WCAG untuk aksesibilitas web.
- Nielsen Norman Group untuk praktik penyusunan form, pengelompokan field, dan alur input.
